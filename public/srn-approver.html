noon ServicePO · SRN Auto-Approver

Approve many SRNs in one go

Paste your SRN links, click one button, and each SRN is confirmed automatically — Business Confirmation → Confirm → Close — until they are all done.

Why an add-on is needed: browsers block one website from clicking buttons on another for security. To click the buttons on service-po.noon.team, the tool has to run inside that site. A tiny, one-time browser add-on (Tampermonkey) makes that possible, using your own ServicePO login — no passwords are ever shared or stored.

One-time setup

  1. 1 Install the Tampermonkey add-on for your browser — tampermonkey.net (works on Chrome, Edge, Firefox, Safari). Click through the store install.
  2. 2 Install the approver script by clicking the button below. Tampermonkey opens an install tab — click Install.
    Install the SRN Auto-Approver script
  3. 3 Make sure you are logged in to ServicePO in the same browser.

Approving SRNs

  1. 1 Open any SRN link, e.g. https://service-po.noon.team/srn/…. A white “noon SRN Auto-Approver” panel appears in the top-right corner.
  2. 2 Paste all the SRN links into the panel (one per line) and click “Approve All SRNs”.
  3. 3 Sit back. Each SRN is opened and confirmed in turn. When finished you'll see “✅ All SRNs approved” with a per-link summary (approved / skipped / errors).

SRNs whose Business Confirmation button is greyed out (already confirmed or not permitted) are safely skipped and listed, so nothing is missed.
